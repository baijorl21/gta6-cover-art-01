Neon Cover Studio — a fully offline web app that turns your own photos into multi-panel, poster-style cover art: five panel layouts with per-panel crop, pan and zoom, Vice City Sunset and Neon Night colour grades, bold auto-fitted caption lettering, and one-click PNG export at 1920 × 1080, 1080 × 1080 and 1080 × 1350. Photos are read locally in the browser and never uploaded; two AI-made sample photos are bundled for an instant demo.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
